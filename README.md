This work presents an implementation and evaluation of a Bayesian framework for P300-based brain-computer interface (BCI) spellers using electroencephalography (EEG) signals. The study is based on the BNCI 2014-008 P300 dataset containing recordings from participants with amyotrophic lateral sclerosis (ALS). EEG signals were preprocessed using band-pass filtering and resampling, followed by epoch extraction and half-sequence construction. The implemented framework employs a generative latent-channel model with Bayesian inference to identify P300-related responses and predict target characters from the EEG signals. The implementation was evaluated across eight participants using four, seven, and ten stimulation sequences. The resulting mean classification accuracies were 64.3%, 80.8%, and 85.3%, respectively, for four, seven, and ten sequences. The corresponding mean BCI utility values were 8.70, 9.03, and 7.24 bits/min. In addition to reproducing the main evaluation, baseline comparison, ablation analysis, and hyperparameter tuning were performed to examine the implemented system. The results demonstrate the effectiveness of the implemented Bayesian framework for P300-based character classification while providing an evaluation of its performance under different numbers of stimulation sequences.
